# Smartphone Abstraction Project

A simple **smartphone abstraction system** developed in **C# with .NET**,  
focused on practicing **clean code**, **object-oriented programming**, and **unit testing**.  
The project allows creating abstract smartphones, simulating calls, receiving calls, and installing apps via derived classes.

## 💻 Requirements to install code

Before starting, check the following requirements:

-   .NET SDK installed (version 8 or higher)
-   Git installed
-   JetBrains Rider or Visual Studio Code (with C# extension)
-   Terminal access (Linux, macOS, or Windows)

------------------------------------------------------------------------

## 🚀 Installing app code

If you have **SSH configured**, run:

```bash
git clone git@github.com:renanzitoo/smartphone-abstraction.git
```

If you **do not have SSH configured**, run:

```bash
git clone https://github.com/renanzitoo/smartphone-abstraction.git
```

After cloning the repository, access the project folder:

```bash
cd smartphone-abstraction
```

Restore dependencies:

```bash
dotnet restore
```

Run the application:

```bash
dotnet run --project SmartphoneAbstraction
```

------------------------------------------------------------------------

## 🧪 Running unit tests

This project includes unit tests using **xUnit**.

To run all tests, execute:

```bash
dotnet test
```
